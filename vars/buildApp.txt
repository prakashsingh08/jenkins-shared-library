<p>
    Builds an application. In this version the Maven build is <em>pretended</em> with
    <code>echo</code>; a later phase replaces it with a real build on a container agent.
</p>

<h3>Usage</h3>
<pre>
buildApp('catalog')      // build the application called catalog
buildApp.cleanup()       // clean up the workspace afterwards
</pre>

<h3>Parameters</h3>
<ul>
    <li><code>appName</code> (String, <strong>required</strong>) — the name of the application to
        build. Interpolated into a shell command, so it must not come from untrusted input until
        validation is added.</li>
</ul>

<h3>Methods</h3>
<ul>
    <li><code>buildApp(appName)</code> — builds the application.</li>
    <li><code>buildApp.cleanup()</code> — cleans up the workspace. Must be called with the method
        name; <code>cleanup()</code> on its own is not a step.</li>
</ul>
